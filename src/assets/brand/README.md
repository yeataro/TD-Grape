## 使用與維護

透明版在亮色背景上視覺較輕；16 px 分頁情境建議保留深色底，以維持紫色圓點對比，避免依賴瀏覽器主題。這是目前預設，透明版同時保留供後续比較。

產品頁首與 About 直接嵌入 mark.svg 的幾何，隨 HTML 一起保存到 TD 元件，不增加圖示請求或私人遠端路由。src/favicon.svg 對應 app-icon.svg。tools/sync_brand_assets.py 可在修改 SVG 來源後同步兩處 UI 與 favicon；需另行重新輸出 PNG。
