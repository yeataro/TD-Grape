# src/editor — retired old entry + files the new editor still uses

Since **Refactor.24 (2026-10-08)** the new editor (`src/editor-react/`) is the only editor entry: a Grape OP's Edit and the service root open it. The old entry in this folder is **retired** — not maintained, not tested, not guaranteed to work (it shares the core with the new editor). Human decision: **mark, don't delete**; unused files are removed when the whole migration is finished. To see old behaviour, open the main or legacy TD.

自 Refactor.24 起新編輯器是唯一入口；本資料夾的舊入口**已停用**（不維護、不測試、不保證能用）。人類決定：**先標記、不刪**，整個遷移完成時再一起處理。看舊行為請開 main 或 legacy 的 TD。

## Still used — move out before cleaning up 仍在使用（整理時要先搬走）

| File | Used by |
| --- | --- |
| `wire_planning.js` | Core bundle (generated by `build:core`). The new editor loads it; the Manager checks its hash. |
| `editor-bootstrap.json` | Node list and type contract (generated). New editor and Manager read it. |
| `editor-library.json` | Built-in subgraph library (generated). The host reads it. |
| `locales.json` | The new editor fetches it for node text. |
| `index.html` | Holds the product version (`brand-version`) that the build and Editor Service read; `build:core` writes the node-browser data into it; the Editor Service requires it in the asset bundle. |
| `favicon.*`, `icons/`, `manifest.webmanifest`, `web_icons.json` | Product icons; likely reused by the new editor (to decide when moving). |

## Old entry only — unused, remove at final cleanup 只屬舊入口（無用，最後清理時移除）

`app.js`, `canvas_ui.js`, `color_picker.css`, `color_picker.js`, `frames_ui.js`, `functions_model.js`, `functions_ui.js`, `graph_ui.js`, `import_ui.js`, `inspector.js`, `qrcode.js`, `select_ui.js`, `selection_ui.js`, `share_ui.js`, `shortcuts_ui.js`, `structures_ui.js`, `style.css`, `uniform_live.js`, `vendor/`.

## At final cleanup 最後清理時

- Rename the new editor page `react-editor.html` to `index.html` (the usual default page) once the old `index.html` is gone, and move the product version out of it into its own place; then the Editor Service no longer needs to name a page for `/`. 新編輯器改名為 `index.html`（一般慣例的預設頁），版本號搬到獨立位置；服務就不必再特別指定 `/` 給哪個檔案。

They stay readable as a reference for how the refactor-era old entry worked; the behaviour baseline is still the legacy product (`../TD-Grape-legacy`).
