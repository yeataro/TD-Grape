# Value Ladder

節點內數值欄位使用共用 `inlineNumericFields`，手勢使用 `installValueLadder`；新增節點應提供型別、值、寫入動作及必要的範圍，不另製一份輸入／拖曳／取消邏輯。Array 的整數長度遵循此規則；由於長度影響接孔型別，提交後共用型別變更流程並更新節點。節點 body 的下拉與數值欄位共用高度、底色及字級，排列由容器決定。

## 2026-09-18：Parameter 整組調值（目前行為）

Parameter 數值列的**參數名稱或型別文字**都可按住中鍵啟動 Ladder。向上／下選級距，開始左右調值後鎖定該級距；每 8 個螢幕 CSS 像素增減一級。浮點提供 `10 / 1 / 0.1 / 0.01 / 0.001`，整數提供 `100 / 10 / 1`，預設分別為 `0.1` 與 `1`。

- 整列各分量套用同一個增量，例如 `[1, 3, 7] + 0.5 → [1.5, 3.5, 7.5]`。展開後的 X／Y／Z／W（或 R／G／B／A）名稱與型別只調整該分量，單值列沿用同一規則。
- 適用共用 `parameterValueRow`：Scalar／Vector 及固定型別值節點、Color，以及未接線的數值 Input 預設值。Bool、已接線 Input、唯讀或忙碌狀態不啟動。未使用的向量分量保留原值，Color 不額外限制為 0–1。
- `int`／`uint` 使用既有型別界限。限制的是整組共同增量；任一分量碰到界限，整組一起停止，避免各自截斷而改變分量差距。
- 預覽只改欄位顯示，放開中鍵才用一次 Graph `change` 提交，產生一筆 Undo／Redo。沒有移動、回到起點或數值實際未變不新增歷史；不對原分量額外截成 15 位有效數字。
- 同節點在畫布或 Parameter 的任何數值欄位仍有未提交文字時，不啟動整組調值，保留文字與焦點。先提交或用 Escape 取消該草稿後即可操作。
- 一般 `render()` 保留進行中的手勢。Escape、Tab、失焦、指標取消、移除控制項、切換節點／圖、唯讀／忙碌或來源內容變更則取消並還原；取消不寫 Graph。

整組與單欄共用同一個 Ladder 手勢引擎。單欄原有的中鍵、Alt＋右鍵、滑鼠／觸控長按及直接拖值入口保留；本次新增的**名稱／型別入口只有中鍵**。

**來源設定的範圍：**目前 Graph Constant 等來源宣告表單與 Native Input 的 X／Y／Z／W 仍是各自欄位，沒有共用整列入口，因此本次不增加來源整組調值。Native current value API 只接受一個 component；未來若支援整組，需有原子批次寫入、失敗回復與一次 TD Undo，不能逐分量送多筆寫入冒充同一次操作。本次沒有新增 TD 輪詢、Python callback 或執行期監看。

驗證：`tests/browser/test_parameter_group_ladder.cjs` 使用本地 fixture 與 headless Chromium，涵蓋兩種標籤、不同初值、固定／通用型別、單分量、Color、未接線預設值、整數界限、單次 Undo／Redo、取消、一般重繪、跨表面草稿保護與極大有限值／零位移精度。此批不涉及 TD 部署或桌面操作。

## 早期設計與驗證紀錄

以下保留初版及 2026-09-10 的歷史紀錄；支援入口與適用範圍以本頁上方目前行為為準。

在可編輯的數字欄位按住中鍵，向上或向下選擇級距，再左右移動調整數值。提供 100、10、1、0.1、0.01、0.001；每移動 8 個 CSS 像素增加或減少一級。換級距保留目前數值並重新計算水平起點，避免突然跳值。

操作參照 [TD 官方 Value Ladder 說明](https://docs.derivative.ca/Value_Ladder)，0.001 是這裡針對 Shader 微調補上的級距。浮層沿用紫色系、顯示目前結果與 Esc 提示，配色集中於 CSS。中英文說明在 locales.json。

## 提交與取消

拖動中只更新輸入框，不修改 Graph、不提交 Uniform，也不因這個手勢要求編譯／PNG。放開中鍵才提交一次；原本其他原因觸發的同步／Preview 機制保持不變。

- Graph 的常數、未接線 Input、Uniform 預設值與 Function 介面預設值沿用一次編輯、一筆 Undo。函式庫副本也只在真正提交時本地化，Undo 可恢復來源參照。
- Expose 的目前值沿用既有 Uniform 寫入檢查；一次手勢送出一次參數寫入，不更改 Graph 預設值／revision／GLSL。這項目前值操作尚未加入 Graph Undo，TD 原生 Undo 整合仍是原有待辦。
- Esc、Tab、失焦、縮放視窗、捲動所在區、取消指標、失去 capture、欄位被重建或變成唯讀都會取消，恢復開始時的欄位值。中鍵點一下而未調整不產生編輯。
- 已接線 Input、唯讀圖，以及 TD Expression／Export／Bind 控制的欄位不接受 Ladder 編輯。伺服器仍會拒絕拖動期間發生的外部值衝突。

鍵盤輸入方式保持可用。這次沒有加入觸控數字拖曳、長按左鍵、無限滑鼠捲動或連續即時渲染；可在實際手感 review 後另做調整。
