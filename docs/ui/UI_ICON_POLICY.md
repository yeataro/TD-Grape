# UI 圖示規則

使用者於 2026-09-10 明確要求：TD-Sgrape 的產品 UI 預設完全不使用 emoji。目標是維持一致、平面、有設計感的介面；不能靠平台彩色 emoji 代替正式图示。

- 控制項、分類、狀態、內建範例與 Help 的自有文字，不加入裝飾 emoji，不指定系統 emoji 字型。
- 優先使用同一套單色 SVG 或經確認的圖示字型，統一尺寸、線寬與色彩；顏色由 CSS 控制。缺圖時以文字備援，不能回退成 emoji。
- 普遍通用且語義明確的箭頭、加減乘除及比較符號可保留在文字中；它們不是用來裝飾。工具列圖示優先固定向量圖形，避免不同字型外觀不一致。
- 只有確實必要、且有通用意義並能以受控的扁平視覺呈現時才考慮例外；不能把「普遍」視為隨意添加彩色 emoji 的許可。
- 图示專用按鈕保留雙語可讀名稱、鍵盤操作與焦點。裝飾 SVG 不重複朗讀，也不攔截滑鼠事件。
- 品牌使用現有自行繪製的葡萄 SVG，不使用葡萄 emoji 或文字拼圖。
- 規則約束產品自有 UI，不刪改使用者自行命名的節點、圖函式或說明內容。

## 本輪接入範圍

源碼審查未發現彩色 emoji 字元。現有文字圓點葡萄已改用正式 SVG；後續依使用者確認的比例固化成 src/assets/brand/mark.svg 透明版與 app-icon.svg 深底版，頁首及 About 內嵌透明版；Undo、Redo、上一層、Shader 下拉與 Create 關閉改為同規格內嵌 SVG。沿用既有靜態資源路徑，不加入字型下載、外部網路、私人 gateway 路由或 Shader 運算變動。新增 Undo／Redo 雙語無障礙名稱。

MDI 仍是後續完整圖示規劃的候選，不因本輪規則加入 1 MB 字型；原型調查仍見 OFFLINE_ASSETS.md。原 .75.toe 與 0.8.5 封存不重寫，本輪只更新現用 HTML／CSS／locale 資源和 Git 源碼。
