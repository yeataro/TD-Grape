# Wire／Link 接線樣式

0.8.196，依 2026-09-23 作者確認實作。

## 操作

Ctrl／Shift 點選可追加或取消選取多條 Wire／Link；右鍵已選線保留整批選取，Wire／Link 樣式及斷開連接作用於整批，混合樣式時不顯示勾選。來源／目的導航與「來源全部轉 Link」仍以右鍵點中的線為準。參見 [選取規則](UI_NAVIGATION.md#click-selection-08196)。

- 在接線上按右鍵，選擇 **Wire** 或 **Link**。Wire 保留原有曲線與型別色；Link 為直線細灰虛線，中間有由來源指向目的的三角形箭頭。常態 1px／60% 不透明度，hover 1.5px／65% 不透明度；中央三角形同步淡化，選取保留醒目回饋，錯誤或垃圾桶操作保留狀態提示。
- 只有 Link 線隱藏時，接孔旁才顯示導航箭頭。箭頭使用與一般 Wire 共用的型別／分量色與 2.5px 線寬；常態圖示 60% 不透明度，hover／鍵盤聚焦恢復完整型別色。按鈕底色與節點 Body 相同，1px 框線沿用節點外框色。輸出與輸入箭頭皆朝右（輸出離開節點、輸入進入節點），不代表導航方向。左鍵選取並 Frame 該接孔透過 Link 連接的所有對端節點；右鍵列出對端，選一個後選取並 Frame。輸入與輸出兩端均可操作，不包括 Wire 對端，也不沿圖遞迴搜尋。
- 線、中央三角形與接孔導航箭頭使用既有瀏覽器懸停提示，多行列出來源節點／接孔及目的節點／接孔；接孔的多條 Link 逐條列出。顯示名稱相同時附節點自訂名稱供辨認。中央三角形沿用接線的選取及右鍵操作。
- 接線右鍵選單只提供 Wire／Link 樣式與接線操作，不提供全畫布的顯示 Link 線切換，以免混淆。
- Wire／Link 與顯示 Link 線的右鍵選項以左側勾選標記表示啟用，不使用加號、選中底色或選中文字色；hover 回饋保留。
- 對端節點選單中，同一對端只列一次。收合節點的合併接孔使用同側所有接孔的 Link 對端。 合併箭頭只依實際連接 Link 的接孔判定型別：全部相同時使用該型別色；只要型別不同（即使原本型別色相同），便使用低彩度、左上至右下的彩色漸層。一般 Wire 與未連接接孔不納入。展開後各接孔恢復各自的型別／分量色。
- 畫布「顯示自訂名稱」同組工具提供 **顯示 Link 線**，亦可用 **X** 或畫布右鍵選單切換，預設開啟。工具列兩個顯示按鈕沿用「還原介面」的普通底色／框線，啟用時只以紫色文字標示。窄畫面收進工具列的更多選單；已移出實驗功能。關閉時隱藏 Link 線與其命中區，接孔導航箭頭顯示並可使用。
- X 不在文字輸入、對話框或進行中的畫布手勢觸發；按住不重複切換。快捷鍵表列出 X。顯示狀態獨立保存為瀏覽器偏好，沿用 0.8.180 的舊選擇；重設實驗功能不影響它。

隱藏 Link 線時，箭頭右鍵選單的每個對端項目左側顯示類別色條，沿用新增節點的色彩混合，文字維持原色。清單下方另有「全部改回 Wire」，只轉換這個箭頭代表的所有 Link；收合箭頭涵蓋同側合併接孔。其他接孔、另一側、普通 Wire 與接線端點不變；一次 Undo 可還原全部。唯讀時仍可導航，轉換按鈕停用；過期選單不操作替換後的圖。

`tests/browser/test_link_target_menu.cjs` 驗證批次轉換作用範圍、Undo／Redo、合併接孔、唯讀與過期選單，以及雙主題色條。

## 批次轉換接線

- 線條右鍵「選取來源／目的」下方提供動作選項「來源全部轉 Link」，只轉換該線來源接孔接出的所有線，不擴大至來源節點的其他接孔。
- 節點單選／多選右鍵提供「轉換接線」二級選單，依序為輸入轉 Link、輸入轉 Wire、輸出轉 Link、輸出轉 Wire。作用於所選節點的對應方向，不遞迴搜尋。選取節點之間的接線依端點歸屬納入，每條只處理一次。
- 沒有需要轉換的接線或唯讀時，選項停用。每次批次操作共用一次 Undo／Redo，保留端點、其他接線及其他 UI 資料。過期圖或選取範圍的選單不執行。二級選單支援滑鼠 hover／點選及鍵盤左右鍵、Escape。

`tests/browser/test_bulk_wire_style.cjs` 覆蓋上述範圍、單選／多選四項操作、唯讀、無變更、過期選單及原有排列選單。

## 選取來源／目的後取景

實驗選項的「選取接線來源／目的時自動 Frame」預設關閉，保留只選取的行為。開啟後，Wire 與 Link 線右鍵選單的「選取來源／目的」會呼叫一般 Frame；動畫開關與時間沿用 Frame 過渡，不另設動畫。唯讀圖亦可導航。設定只保存在瀏覽器，不寫入圖、版面或 Undo。Link 接孔箭頭原有導航行為不受此開關影響。

`tests/browser/test_wire_endpoint_frame.cjs` 驗證來源／目的、Wire／Link、開關與 Frame 動畫、唯讀、保存與重設，以及圖不變。

## 資料與邊界

Wire／Link 是同一種圖接線的顯示樣式，不改變 GLSL、型別、計算、接線合法性或一般上下游選取。新接線預設 Wire。Link 記為 `edge.ui.style = "link"`；切回 Wire 移除這個顯示欄位。

樣式跟隨圖保存，支援 Undo／Redo、Duplicate、剪貼簿、Function 內部接線及函式庫交換。從節點抽出 Function 時，既有邊界合併規則仍成立；多條邊合併為單一邊界接線時，合併邊使用第一條邊的樣式，各內部支線保留各自樣式。

樣式編輯走既有 layout 編輯路徑；後端語意指紋排除 edge UI，不因樣式變更改變 Shader 語意。顯示 Link 線是瀏覽器偏好，不寫入圖或 Undo；導覽是選取與 Frame，唯讀圖亦可使用。右鍵清單若所屬圖已替換，不執行過期選項。
