# 新編輯器的畫面規則

適用：`src/editor-react/` 的所有介面。寫或改任何介面前先讀；顏色細節另見 [顏色系統](COLOR_SYSTEM.md)。

整理日期：2026-10-09（Refactor.54.3 清理後）。人類：到這裡畫面的規則差不多都出現了，當作一個邊界。之後新規則照同樣格式加在這裡，寫出處；和這裡衝突時先問人類。

能用測試把關的，標 **〔測試〕**（`npm run test:editor`）。

## 一、怎麼決定

1. **舊產品的行為是預設。** 舊產品沒有的行為要標成「新行為」、說理由、等人類同意。每輪的範圍文件放一張舊行為對照表（AGENTS.md「每輪工作」）。
2. **照舊產品「為使用者做了什麼」，不照「它怎麼做」。** 不抄舊產品的全域重繪、散落各處的顏色、混在一起的設定邏輯。
3. **外觀做到要硬編碼，就跳過並記下來。** 外觀功能都不值得讓架構變髒；一定要的功能，要有共用能力，先討論（人類 10-09）。
4. **先把基本能力做好，外觀與手感留到調整期。** 標準功能都做完後，有一段多輪調整期；在那之前，外觀只求可用、結構乾淨。
5. **停用或覆蓋 React Flow 的內建行為，要先向人類報告**，並列在該輪範圍文件，寫出原因。目前的例子：React Flow 的選取已關閉，改由編輯協調者決定；雙擊空白處不縮放，改成打開 Create node。
6. **加架構沒有的新能力前，先說明加什麼、為什麼、不加會怎樣**，等人類同意（AGENTS.md）。例：選單的分類子選單還沒做，就是在等這一步。

## 二、顏色

全部照 [COLOR_SYSTEM.md](COLOR_SYSTEM.md)。重點：

- 三層：調色盤（唯一有色碼）→ 用途 → 元件。元件只寫用途名。**〔測試〕** `test_themes.cjs`。
- 一個墨色依共用強度提亮成各層；選取與焦點才混強調色。
- **按下的開關**：一般開關用介面的低彩度淡紫（`--pressed`）。只有**模式開關**用選取綠（`--pressed-mode`）；模式開關指會改變拖曳、選取等互動的開關，目前只有框選。互動變很大的才高亮提示（人類 10-09）。
- 被 TD 鎖定（驅動）的值保持深色；可編輯的值用比卡片亮一階的顏色（`--surface-node-field`）。
- 捲軸、勾選框都跟主題走；換 TD 主題時會自動換掉。

## 三、尺寸與文字

- **字級只寫有名字的級**（`--font-*`，搭配固定行高 `--line-*`），不寫像素字級。**〔測試〕** 這樣中英文每一列一樣高。
- **字型跟著語言**：英文 Verdana、繁中蘋方或微軟正黑、其他語言系統字型優先。都寫在 `theme/sizes.css` 一處。
- **尺寸是兩檔**：Standard（預設）、Comfortable。列高、按鈕、間距都是 `sizes.css` 的變數。畫布上浮動的東西之間、到畫布邊的距離，都用 `--float-gap`。
- **介面文字一律寫 `tr('區域.項目', 'English')`**，中文放語系檔（design-interview Q34）。訊息要說出真正做事的是誰：TD、我們的宿主，還是編輯器。

## 四、部件（widget）

- **只用我們自己的部件。** 瀏覽器內建、會跳出東西的控制項（例如下拉選單）不能只改顏色就拿來用（人類 10-09）。**〔測試〕** 元件裡不寫 `<select>`。
- 共用部件放在幾個固定的地方，新需求先找現有的：
  - [controls.tsx](../../src/editor-react/controls.tsx)：圖示按鈕、下拉選擇、分段按鈕、彈出面板、可折疊段落、對齊表格、數量標籤。
  - [DropdownMenu.tsx](../../src/editor-react/DropdownMenu.tsx)：選單。
  - [NumberField.tsx](../../src/editor-react/NumberField.tsx)：數值框。
  - [ValueFields.tsx](../../src/editor-react/ValueFields.tsx)：一組數值。
- 部件只負責「顯示與操作」，內容和選了之後做什麼屬於用它的人。
- 跳出來的選單畫在頁面層，從縮放中的節點叫出來也要落在按鈕下方。
- 停用的按鈕仍然可以滑過，提示要說明為什麼停用。
- 勾選框目前用瀏覽器原生的加上強調色，照舊產品。

## 五、面板與版面

- **所有面板一張表**（[panels.tsx](../../src/editor-react/panels.tsx)），每列寫名字、預設位置、內容。新面板就是在表裡加一列。表的順序就是預設分頁順序。
- **版面**（[layout.tsx](../../src/editor-react/layout.tsx)）只排代號：哪一區、哪一組、寬度。它是個人偏好，只存在這個瀏覽器，存的東西讀不懂就回到預設。
- **面板只是內容。** 換外殼不換內容（Q47 5a）；內容來自正在編輯的那張圖（Q47 4），不讀全域。
- 面板分頁標題照舊產品：小字、一般粗細，顯示中的才加粗。

## 六、互動

- **游標只有一張對照表**（`style.css` 最後，照 TouchDesigner）：滑過什麼都是箭頭；只有在畫布上按住平移時，才是十字方向箭頭。元件不自己寫游標。
- **浮動提示不擋編輯。** 找到草稿、衝突這類提示，浮在功能列下方，彼此用同一個間距排下去。提示分三段：說明、比對表（`AlignedRows`）、動作列。
- **個人偏好跟著人走，存在這個瀏覽器**：語言、主題、大小、版面、Body 拖曳。專案屬性才跟著 TOE（AGENTS.md）。
- **套用設定不重新整理頁面**，否則會洗掉 Undo 紀錄和訊息紀錄（R.53 語言選單的教訓）。
- **行為開關都是暫時的**（[options.ts](../../src/editor-react/options.ts)，Q64）。調整期逐一決定：要嘛變成正式設定，要嘛攤平，不留永遠藏著的開關。

## 七、檢查

- 每次改介面都要跑 `npm run check:editor` 和 `npm run test:editor`。
- 再用內建瀏覽器接真實 TD 看一次人看得到的狀態：顏色要用實際算出來的值核對，不要只看截圖。
- 測試不打開人類機器上的瀏覽器分頁。
