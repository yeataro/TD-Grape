# Sources 面板整理

2026-09-23 使用者確認後授權由簡到難分批實作。所有卡片與搜尋列的調整都在 Sources／來源面板，不是 Add Node 面板，也不改畫布節點的顯示模式。

## 第一批：0.8.176

- Input／Inputs 面板正式改名 Sources／來源。
- 搜尋框置頂、占滿整行；TD／共同名稱下拉選單移到第二行，同列提供顯示備註。
- 預設最上方依序為 Uniform、Graph Constants、Specialization Constants。
- 一般卡片的 Output 放在 Body 最上方。
- 節點的「編輯來源」按鈕移到設定；數值與數值來源操作保留在參數頁。

顯示備註是瀏覽器偏好，不修改圖、來源、接線或 Undo。切換時保留數值控制 DOM。Sources 仍沿用既有 workspace panel ID，已保存的面板位置不受改名影響。

## 第二批：0.8.177

- 分類可用標題旁上下箭頭手動排序，同層分類之間移動，保存為瀏覽器顯示偏好；不改宣告順序。搜尋時停用排序；暫時未顯示的分類保留順序。
- Graph Constants 在來源卡片 Body 中直接編輯數值；Specialization Constants 沿用原生數值寫入路徑，Uniform 沿用既有即時寫入路徑。
- 第二行加入最小化顯示切換。依作者後續修正，採縮減上下留白及圓角，維持文字大小與標題列在上方，取代名稱移到左側的提案。隱藏 Output 名稱、型別與接孔，有數值控制的卡片保留控制，其他來源折疊，不丟失編輯／建立引用入口。恢復一般模式時保留原先折疊偏好。
- 最小化與顯示備註可獨立切換；警告不隱藏。分類及卡片標題一起壓縮。觸控保留較大的按鈕命中高度，避免整體縮放造成文字與操作區太小。
- Graph Constants 使用既有型別控制、圖編輯與 Undo 路徑；分量修改讀取當前宣告，不使用建立控制時的舊數值。支援純量、向量、矩陣、布林及整數範圍。切換顯示與原生輪詢保留尚未提交的數值草稿，切換圖後的舊控制不能寫入新圖。

`tests/browser/test_source_workspace.cjs` 覆蓋面板布局、值修改、Undo／Redo、過期控制、最小化、正常折疊恢復、排序及顯示偏好重新載入。與既有 Sources 卡片／呈現／選單檢查一起使用。

未增加新的來源或產碼能力。畫布 Float／Vector 常量節點不屬於本輪 Graph Constants 要求。
