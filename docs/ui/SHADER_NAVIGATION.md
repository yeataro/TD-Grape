# TD Shader 路徑切換

點 TD 路徑旁的下拉箭頭，可以切換目前主元件管理的 Sgrape MAT／TOP。清單顯示完整 TD 路徑及種類，圖內的 Graph／Function 導航保持獨立。選單每次開啟才讀取一次，不新增持續輪詢。

沒有未套用編輯時直接切換。有草稿時提供「套用後切換」和「保留草稿並切換」；關閉對話框會留在原 Shader。草稿保存在目前瀏覽器分頁，切回時走既有匯入檢查。即使 TD 已有較新 revision，也能先檢查舊草稿，不會自動覆寫。關閉分頁會清除未套用草稿；儲存失敗、編譯失敗或正在提交圖／Uniform 時都不會直接離開。

新增唯讀 `GET /api/<shader-id>/shaders`，沿用既有身分與來源檢查。探索時不註冊或修改 OP，排除範本、其他主元件與無效身分；重複 ID 優先保留已註冊實例。較新版本與損壞 metadata 顯示為停用項目。切換使用相同 origin 的 `/shader/<id>/`，重用本分頁權杖；私人 gateway 的允許路由另行更新，不加入產品。
