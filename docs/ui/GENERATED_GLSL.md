# Generated GLSL 顯示節點

0.8.189，依 2026-09-23 作者確認實作。

## 操作

在新增節點搜尋 `Generated GLSL`。此節點只顯示目前所在 Vertex／Pixel 階段產生的完整 GLSL；進入子圖時仍顯示該階段的程式碼，不把子圖片段冒充獨立 Shader。

每個畫布各最多一個，Vertex、Pixel 與各子圖分別計算。新增後該畫布的新增入口不再列出它；刪除後恢復。複製、貼上或合併子圖等操作若導致同一畫布有兩個，整次操作拒絕並回復，不默默刪除其中一個。匯入重複顯示節點亦拒絕。

- 沿用 Note 的標題高度、選取時顯示標題、顏色／透明、字體倍率／對齊、移動、折疊及雙向調整大小。初始大小 480 × 300 圖單位，寬高上限各 3000。預設純黑底，調色盤亦可選純黑；字級倍率為 0.1–10，Note 仍為 1–10。
- GLSL 區塊唯讀，可選取、複製及捲動；沒有編輯文字的入口。沿用既有 GLSL 語法上色。
- 圖的產碼內容變更後延遲 250 ms 更新；只移動或修改顯示節點外觀不重新產碼。
- Parameters 顯示相同內容，並提供 Refresh GLSL。產碼錯誤取代舊內容；較晚抵達的舊圖／舊階段回覆不覆蓋新結果。
- 顯示程式碼以目前編輯中的圖為準，不表示該版本已 Apply 或已通過 TD 原生編譯。此節點使用既有 validate 產碼入口，不 Apply 圖或改變 TD 材質。

## 保存與邊界

節點身分及外觀像 Note 一樣隨圖保存；GLSL 本文只存在當前顯示與記憶體快取，不寫入圖、草稿或節點參數。節點沒有接孔，不參與 Shader 語意、程式碼、指紋及斷線診斷。

唯一限制以原始畫布計算，不以編譯時展開的呼叫實例計算。同一個含顯示節點的子圖仍可被多處呼叫。

- `tests/browser/test_generated_glsl_viewer.cjs`：實際搜尋新增、唯讀與安全上色、複製／貼上拒絕、外觀不重產、無重繪的編輯更新、階段／子圖切換、非同步舊回覆隔離、錯誤與重新整理、刪除／Undo。
- Note 既有瀏覽器檢查覆蓋共用外觀與大小操作。
- `tests/td/test_generated_glsl_viewer.py`：目前載入的 TD validate 入口與 TOP／MAT／Phong／PBR Master 比對；新增顯示器後輸出不變，現場圖、Shader DAT 及狀態保持。
