# 共用預覽面板精簡筆記

2026-09-16。這份筆記整理使用者新提出的 UI 方向；以下精簡尚未套用。

核心：讓影像占用盡可能大的面板空間。控制項、狀態與資訊盡量不占固定高度。

- 開啟 Viewer：可先隱藏按鈕，保留呼叫 TD 原生 Viewer 的能力。
- 重新整理：目前 WebRTC 實作的實際用途是重新連線、取回共用預覽控制權，並非逐張刷新。待評估名稱與呈現；建議縮成小圖示，在斷線／被接管時明顯顯示。
- 即時預覽：目前勾選控制此頁是否維持串流連線；關閉會釋放此頁的 peer。保留這個能力有停止預覽負擔的意義，建議從常駐勾選框收進小選單；選單方案仍待確認。
- 已連線文字：已有面板狀態燈，可移除重複文字。錯誤／斷線等需要使用者處理的狀態仍需清楚呈現。
- 解析度：放在影像區內角落，精簡疊加顯示，不另外占一列。
- 操作提示：先隱藏「點選預覽後可操作／H 重設 Viewer」等常駐文字，操作本身保留。
- 來源路徑：助手建議保留精簡顯示，協助辨認共用預覽被其他頁面接管後的實際來源；呈現位置尚未定案。

目前進行的尺寸實驗：Graph UI 預覽區拖曳期間只縮放現有影像，放開並穩定後才更新 OP Viewer COMP／TOP 的尺寸；僅由目前取得連線的頁面提出更新。
