2026-09-16。依最後確認的範圍，以下精簡已於 0.8.76 套用。

核心：取消預覽影像下方整列，將空間還給影像；上方既有控制列保留。

- 開啟 Viewer：本機與遠端皆隱藏按鈕，保留既有 TD 原生 Viewer 呼叫能力。
- 重新整理：保留原位置的小圖示，負責重新連線、取回共用預覽控制權。
- 即時預覽：保留原勾選框；關閉會釋放此頁的 peer，重新連線會再次啟用。
- 狀態文字：依最新決策保留在上方控制列，包含已連線、失敗、被其他頁面接管等狀態；綠燈與影像內的異常訊息也保留。
- 解析度：放在影像區內角落，精簡疊加顯示，不另外占一列。
- 操作提示：移除「點選預覽後可操作／H 重設 Viewer」等常駐文字；操作本身與 Help 內說明保留。
- 來源路徑：保留目前顯示位置。本輪不將控制項搬到 Panel 標題列或分頁上。

解析度角標不攔截滑鼠／觸控事件。未來可評估「來源解析度 → 預覽解析度」的對照，以及 TOP Viewer 的通道檢視；待使用者定義後續 Viewer 能力再設計，本輪沒有新增這些功能，也沒有改動尺寸同步時機。

尺寸實驗已於 0.8.75 實作：Graph UI 預覽區拖曳期間只縮放現有影像，放開並穩定 350 毫秒後才更新 OP Viewer COMP／TOP 的尺寸；僅由目前取得連線的頁面提出更新。這不表示下列實際體感問題已解決。
