# 節點工作流程：0.8.84 決議

2026-09-17 使用者確認實作。此文件區分已決議範圍與後續筆記；實際交付與驗證見 STATUS／TESTING。

## 本輪

- Vector 2／3／4 先試作無輸入、手填分量、單一完整向量輸出。Combine／Split 各自維持用途。Replace 提供完整基底與分量覆寫，只有完整輸出；分量輸入不折疊，輸出另列。
- Vector／Color RGBA 的手填值可在緊湊同列與展開的具名分量列間切換。保留數字底色、Value Ladder、色條與調色盤，不把整顆節點折疊。
- 一般節點建立時分配唯一遞增名稱。工具列用「自訂名稱」文字按鈕切換預設名稱／自訂名稱；切換只改顯示。自訂名稱模式直接在標題編輯，Enter 或失焦提交、Escape 取消；空白转底線，識別字限制與重複檢查保護 GLSL，IME 組字完成後處理。
- Uniform／Graph Constant／Spec Constant 等來源引用以宣告名稱為主標題、種類為副標，不設另一個可獨立改名的別名。改名應編輯共用來源。
- 標題提供一個主要型別或模式快捷下拉，複用 Parameter 的資料與行為；不為每個參數再建立一排控制。型別切換造成接線不合法時，沿用現有未套用／診斷流程，不另設一套拒絕切換規則。
- Inputs 分類的建立入口用 New／新增，引用列仍可用加號放置節點。Graph Constants／Spec Constants 分開；Spec Const 短標搭配完整 Help。TD Built In／TD 內建來源提供既有來源的另一個尋找入口，不強制同色。Texture Coordinates 名称暫留，以 `vUV.st` 補充辨識，分類不當作 sampler 或常數。
- 導航併入工具列，移除 Graph 標籤；縮放與置中移至畫布角落。工具按組換行。工具列浮動為程式 flag，預設固定；浮動空白處可穿透操作。頂欄收合按鈕移至 Layout 左方。
- 使用者允許刪除舊統合式 Vector X 開發測試圖／定義兼容路徑：此次為 Alpha 前一次性例外，不對新 Vector 製作保留舊 I/O 的遷移。不能據此任意刪除其他使用者資產。新模板與預設圖必須同步。

## 不納入本輪

- Parameter 整體排版、Inputs 卡片內直接編輯來源值：先讓節點介面有可參照的行為。
- 整顆節點折疊、合併接孔顯示、多選浮動工具與 Comment：接孔呈現／操作位置仍待試作。
- 中途預覽、Canvas Backdrop：保留目標，等節點工作流程穩定；Backdrop 是後續確定要做的能力。
- TOP 其他貼圖維度、陣列與矩陣、完整整數向量管線：分開驗證型別、取樣索引與原生綁定，不在本輪混入。
- TD 拖放到瀏覽器的跨程序調查、QR code、實體 iPad／Safari 回驗仍是後續事項，不自動啟動。

名稱切換的正式圖示、來源卡片編輯位置、TD 內建項目的更完整分類仍可依使用回饋調整。本輪使用文字按鈕及現有分類邏輯。

## 0.8.84 小幅追加

- 標題型別下拉移除常態外框、底色，以文字與箭頭保留快捷入口。
- 節點右下角可水平調寬。後續確認區分最小／預設／最大寬度：最小保留現有基準；預設容納整顆節點可讀資訊；最大先用寬鬆的 1200px。尺寸隨圖保存，僅屬圖面修改，一次拖曳對應一次 Undo；不更新 Shader。
- 調寬提示改成與節點圓角同圓心的圓弧，可用 `nodeResizeHint` flag 隱藏；節點移動游標預設一般箭頭，保留 `nodeDragCursor` 設定。
- Uniform／Vector 輸出改顯示 `out`；副標歸屬與型別以中點分隔，型別文字不能被箭頭遮住。有無選單的標題維持同高；Texture Coordinates 的 `vUV.st` 改放右側單行副標。

## 後續確認：名稱、數值與 Auto

- 畫布預設名稱模式不重複原始用途；自訂名稱模式右側補回原始用途及既有型別快捷，移除 GLSL／Constant 分類堆疊。來源引用持續显示種類與型別。Parameter 左側固定原始節點名、右側名稱，不受畫布開關影響；工具列文字為「顯示自訂名稱」。
- 所有數值分量（含四分量）統一支援左鍵水平拖曳與淡色 slider；Value Ladder 的外觀簡化留到下一輪。
- Replace 最終只加入主輸入 Auto；取消手填／預設分量的提案已撤回，保留原先未接基底可使用手填值的行為，避免空節點直接變成錯誤。
- 自動斷開新不相容接線做成程式 flag，預設開啟；先推導 Auto，再處理本次新失效線，同一步 Undo。關閉後保留原草稿提示。
- 舊固定 Vector 節點的清除／轉換仍未決；不因這批顯示調整刪除現有節點。

- 2026-09-17：Texture Coordinates 按功能歸入 Attribute／屬性來源色系，TOP 的畫布 UV 沿用同色；TD Position 同組。先用低飽和暖灰褐，可再調整；型別接孔與線條不變。MAT 副標改為 UV 0，TOP 保留 vUV.st。
- 2026-09-17：畫布直接改名時標題列不可因輸入框或驗證錯誤增高，維持原標題行高與接孔位置。
- 2026-09-17：畫布副標整組靠右；Auto 或指定型別的選單文字也靠右，文字與箭頭維持一致間距。
