## 本輪定案

- 自動節點寬度依控制項、標題與接孔結構計算，不因滑桿數字或色盤產生的小數位數改變。數值精度與手動寬度保留。
- 數值滑桿直接雙擊進入文字編輯並全選；單擊與拖曳保留。
- 接孔右鍵開啟相容節點選單；選擇後進入放置預覽，再點一下才新增及接線。取消不改圖、來源、歷史或既有連線。拖線到空白處原有已知位置的新增流程保留。
- 預覽沿用節點實際尺寸：圓角外框、名字及標題分隔線，空白內部；實線 1.5px，亮紫色框線及文字。無外陰影；Glow 16px，Simple 關閉，Professional 及列表後續模式開啟。臨時線為虛線，使用起始接孔原色／分量色。預覽強調色不受介面亮度滑桿影響。明亮模式使用較深紫色，由實作者決定。
- Excellent、Legendary、Godlike 的 Source 卡片只有 available 狀態發光；未建立或不可用來源不發光。
- 連線右鍵加入「選取來源」「選取目的」、水平分隔線、「中斷連線」。來源／目的只選該條線的直接端點，斷線只修改該條線並可 Undo。

## 0.8.156 實作與驗證

本輪定案已實作。數值欄位以固定量測樣本保留基本閱讀空間，實際值保留完整精度；標題及接孔結構仍可影響預設寬度，手動寬度優先。

放置預覽使用隔離的節點／来源資料及同一張節點卡片的 renderer 量測，再顯示純外框。量測不把節點、來源或函式寫入目前圖，也不訂閱原生值。點擊放置沿用既有 instantiate／commitPlannedWire，完整型別驗證成功後記錄一次歷史。Esc、離開視窗、唯讀、切換圖及外部操作取消預覽；既有輸入的線在成功放置前保留。
