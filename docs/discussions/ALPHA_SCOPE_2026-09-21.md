## 來源與運算的分類原則

使用者最新界線：有資料輸入並進行計算的歸運算；只輸入 index／layer、用來挑選 TD 已有資料的仍可歸來源。分類看輸入的用途，不能只算接孔數量。

- `TDBoneMat(index)`、`TDInstanceMat(index)`：來源；索引是選哪筆資料。
- `TDDeform(position)`、`TDInstanceColor(index, color)`：運算；有待處理的資料。
- 光照函式同時接燈光 index、位置／法線等：运算，不因有 index 改歸來源。
- `TDCheckDiscard()` 等無回傳值的宿主操作：另標示執行／輸出流程，不能因沒有輸入而當作來源。
