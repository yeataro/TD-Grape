# 左側 Library 與 Create 分類：0.8.3 已接入

2026-09-10 使用者已選定三個主 Tab「節點／圖函式／範例」，圖函式內再分「此 Shader／內建／個人」。分類與「圖函式」名稱不再待答。0.8.3 已接入正式 UI，下面區分已完成的左側分類與 Create 後續方向。

## 已確認結構

| 主分頁 | 內容 | 操作語意 |
|---|---|---|
| Nodes／節點 | GLSL 運算、Constant、Uniform、取樣、TouchDesigner builtins | 在圖中放置一個節點；Math、Inputs、TouchDesigner 是次分類。 |
| Graph Functions／圖函式 | 可進入查看／編輯的節點子圖，分此 Shader／內建／個人 | 放置 Call；此 Shader 的本地定義可編修，唯讀來源首次編修時建立本地副本。 |
| Examples／範例 | 完整 Shader 預設圖 | 載入整份圖，沿用目前替換檢查，不與新增單一節點混在一起。 |

「圖函式」描述由節點子圖定義的可重用函式，並不是宣稱 sin 等 GLSL 函式不是函式。GLSL／TD 的原子運算仍在「節點」，Add、sin、TDDeform 等專有名稱保留英文。

## 圖函式的來源與編修

- **此 Shader**：目前 Shader 的本地定義；編修同步影響同一 Shader 內引用此定義的 Call，TD 材質成功編譯後更新，失敗保留上次成功結果。
- **內建**：TD-Sgrape 提供的共用函式庫。來源唯讀，進入查看不建立副本；首次編修遵循既有本地化契約。
- **個人**：使用者函式庫；進入 Shader 使用的來源同樣唯讀，編修前本地化，不向使用者資料夾或其他 Shader 回寫。

來源以小型次分頁呈現，固定一個內容區，減少長列。此分類決策不改動現有複製 Call、Make Independent、來源快照、本地化與同來源重用規則。個人分類位於 TD-Sgrape 編輯器內；資料位置可連結 TD Palette 或 TD 使用者資料夾。

## 建立操作的文字細化

- **New Function／新建圖函式**：新增空白定義，從 Input／Output 開始。
- **Group Selection／將選取節點建立為圖函式**：把目前選取的節點收成定義，以 Call 取代原選取範圍。沒有可用選取時停用。
- 放入已存在定義使用 **Add to Graph／加入圖中** 或拖放；避免含混的「Add Function」。

這些按鈕文字是實作時的用語細化，尚非使用者逐字選定的標籤；不影響已確認的分類結構，也不需要因此阻擋分類實作。

## 搜尋與 Create

搜尋以目前主分頁為範圍；圖函式搜尋可跨三個來源並保留來源標題，避免誤以為某個項目消失。若需要跨節點／圖函式的全域搜尋，可留給 Create，不先增加第二套搜尋控制。

Create 後續可採精簡類別分頁加搜尋；目前仍是精簡類別選單加搜尋，拖線建立時只列相容項目，保留型別提示。空白畫布建立與拖線建立共用介面；左側 Library 開關不影響它。類別可依實際項目數調整，不把所有 Library 管理功能塞進浮動視窗。分類與建立操作留在左側、靠近畫布，不移回頁面最上方。

## 驗證狀態與實作順序

先前互動提案已在 Chromium 的 1024／736／360 px、明暗兩種模式檢查，搜尋、分頁、建立示意、Create 開關與窄畫面無橫向溢出。它是獨立提案，不連 TD、不寫工程；示意資料不是正式節點 catalog，也不代表新增 Auto 型別。原提案展示的 Functions／Sgrape 文案應以本文件新確認的 Graph Functions／內建為準。

0.8.3 已完成左側分類與 16 項瀏覽器互動、14 項 TD 連線、6 項原生核對。涵蓋實際拖放、同 ID 不同來源版本、個人保存與重用、來源首次編修、本地空白／群組建立、範例替換與 Undo、唯讀保護及中英文窄畫面。原 MAT／TOP GPU 往返差皆 0，三個匯出產品 TOX 另經新程序重載。右側 Parameter／Live／Help 不變。

來源卡片以小字區分現行來源與此 Shader 保存的舊快照，重複拖入同版本仍重用；並未加入自動向上同步或自動升級。搜尋記住每個主 Tab 的內容與捲動位置，圖函式搜尋跨來源；點選來源 Tab 後回到該來源並清除搜尋。
