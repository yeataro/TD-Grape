# 下一輪 UI 與圖根操作筆記

這份文件記錄目錄遷移期間的使用者修訂，尚未因此實作。具體外觀可在下一輪繼續調整。發生歧異時，回看原規劃並討論偏差原因；舊規則不是不可修正的限制。

## 圖根的恆常節點（設計方向）

- Uniforms／Colors、Constants、Buffers、Attributes、Samplers 等集合可以成為圖根恆常入口，類似 Color Output。按目標與 stage 提供對應集合，沒有模板的集合起始為空。
- 點擊後在 Parameter 面板編輯；節點上的 `+` 與面板新增走同一操作。
- 集合節點呈現現有定義，不另建一份資料。單項引用節點仍可並存。
- 恆常集合節點不能刪除、不能打包進 Subgraph；集合中的項目仍可刪除。一般引用節點可刪除，且不等於刪除來源。
- 打包時來源保留外層，建立必要 Input 並保留來源名稱，方便辨識。
- 空集合的緊湊顯示、隱藏方式、混合框選的回饋是待實作時檢視的細節。

## 面板與 Layout

- 保持左側欄／中央網路圖／右側欄的整體結構，面板可以跨左右側欄移動。
- 拖拉分頁必須支援同組內排序，以及合併到另一組時選擇插入位置；提供清楚的插入提示，順序隨 Layout 保存。
- Layout 入口改為精簡按鈕或下拉選單，提供面板顯示狀態、切換預設及使用者配置、保存目前配置、管理配置。Wire 的預設名稱僅為操作參考，不代表照搬所有布局。
- 使用者先自行整理配置，再選定預設與其他選項。
- 作用中分頁不加底線，刪除為底線保留的高度；非作用中分頁變暗，標題列使用整體 UI 的中性色。
- Parameter 的節點底色標題四周不留 gap，高度降至與分頁列一致；一般 Parameter 內容需精簡。
- 左右側欄的快速收合入口各放一側。面板收合圖示需清楚、精簡。
- 連線刪除入口需改善可發現性。目前程式支援選取連線後按 Delete／Backspace；這不是新的已完成 UI。
- 畫布節點的註解直接顯示內容，移除「Comment・註記」標題與展開箭頭，取代先前畫布註解可折疊的做法。文字統一使用一般內文色，不跟隨節點色；此修訂指畫布節點，Parameter 編輯區未因此改動。

## Label 產碼修訂

Label 改為對應程式行末的註解，拿掉 `Label:` 前綴，取代先前上方獨立註解的規則：

```glsl
vec4 sg_n_texture = texture(sTD2DInputs[0], sg_n_uv); // 中文?
// Comment 保持在下方
```

Label 不用作 GLSL 識別字，仍需防止換行或特殊字元改變程式語意。多行產碼、無獨立程式行的節點及 Subgraph 展開的放置位置在實作時確認。此修訂尚未改動目前編譯器。

Label、Library／本地來源資訊在畫布節點上的配置仍保留決策。
