# 0.8.5 完整錯誤詳情

失敗提示中的「錯誤詳情」可點擊或以 Enter 收合，文字獨立捲動。完整 server error 優先，沒有時保留 structured diagnostics 文字。即使沒有精確節點位置，也能查看原因。切語言、定位與其他 UI 狀態不會清掉錯誤，並保留展開及捲動位置；新編輯、Undo、成功提交或重新載入一起清除過期位置與文字，新一筆錯誤預設收合。

錯誤內容只以 textContent 呈現，可選取，不解讀 HTML。窄畫面診斷固定在 Graph 導航與畫布之間，有高度上限，剩餘高度留給畫布。12 個瀏覽器情境包含多行、超長行、HTML 字樣、一般錯誤、語言、捲動、鍵盤、清除與真正 Parameter 型別切換。

以下為0.8.4來源映射的原驗證紀錄；其中只靠 footer 保存文字的限制已在0.8.5補齊。

# 編譯診斷與節點定位

0.8.4 在畫布上方顯示失敗提示。能確定節點時提供「前往節點」；使用者點選後才切換 Vertex／Pixel、進入對應圖函式並選取置中，不自動打斷正在看的畫布。高亮以 stage、Function ID 與節點 ID 判斷；同一 Function 的不同引用共享定義。

編譯器生成 sourceMap，記錄每條節點敘述的行號、原始節點身分與函式路徑。中繼介面敘述歸到其所在 Call。GLSL 文字、參數 binding 與 semantic hash 不因這些資料改變，未加 #line，也未把外來文字當程式執行。Function 中同名節點與不同 stage 的相同 ID 不再互相覆蓋。

TD 編譯失敗透過 Info DAT 讀取。目前在 TouchDesigner 2025.32820 實測的格式是帶有完整 Shader DAT 路徑與行號的 ERROR 訊息；僅在實際 DAT 內容和該次編譯結果完全相同時才使用映射。殼層、宣告標頭、未知 driver 格式或不匹配的來源不猜測位置，完整文字仍在狀態訊息中。官方入口：[GLSL TOP](https://docs.derivative.ca/GLSL_TOP)、[GLSL MAT](https://docs.derivative.ca/GLSL_MAT)。

錯誤回應綁定送出時的草稿；途中修改後不接受舊圖的位置。平時按編輯版本判斷高亮，避免每個節點重複序列化整張圖；Undo、新編輯、成功提交與重新載入會清除診斷。來源圖、Function scope、公開 Uniform 與編譯交易規則維持；失敗保留上次成功输出。

驗證：新增 8 核心測試，總共 87；六個原範例和 138 張既有图的執行結果基準保留。13 項真實瀏覽器／TD 測試涵蓋根節點、巢狀錯誤、跨 stage 同 ID、Undo、過期回應與 360 px 英文布局；10 原生檢查包含 5 種實測錯誤位置、來源不匹配、像素及工作圖保留。17 項 Library 回歸另涵蓋 Function Input／Output 的正確接點型別。產品 TOX 再於獨立程序重載，細節見 VERIFICATION.md。

測試使用獨立 runtime，僅將明確的測試 literal 變成未宣告識別字以觸發實際 TD 編譯錯誤；此注入只存在測試工作檔，沒有進入來源或產品。測試區已移除。

限制：不是所有 TD 版本或 GPU 驅動格式都已覆蓋；目前不逐項定位宣告面板、不推測連結階段錯誤，未提供完整歷史 emitter 重播。錯誤文字仍保留作為這些情況的依據。
