# Uniform 預設值與目前值 — 0.2.1

選取 Exposed Uniform，在右側 Parameter 面板可看到兩組數值。

| 欄位 | 用途 | 修改後的行為 |
| --- | --- | --- |
| 目前值 | 這個 Shader 正在使用的 TD 參數值 | 網頁按 Enter 或離開欄位後直接更新 TD；TD 端修改也會同步顯示 |
| 預設值 | 建立／重設參數時採用的值 | 更新 Graph 與 TD 參數的 Default，保留正在使用的目前值 |

取消 Expose 時以圖內預設值驅動材質，保留已停用的原有 TD 參數關聯。重新 Expose 沿用原有目前值／控制關係。TD 原生 Reset 使用最新預設值。

目前值的修改只寫入指定 Shader 的指定 numeric 分量，不更換 GLSL MAT、不重寫 Shader 程式，也不改 Graph revision。面板或預覽可見時約每半秒讀回 TD 值；隱藏頁面停止讀回，沒有數值變化就不額外抓取預覽。正在編輯、尚未送出的欄位不會被同步回應覆蓋。

如果另一端在輸入期間改了同一分量，伺服器拒絕過期寫入並顯示提示；離開欄位後會顯示最新值，可再次編修。不同分量的修改不互相覆蓋。

Expression / Export / Bind 控制的分量先只顯示實際結果和模式，其他 Constant 分量仍可編輯。網頁不會把既有控制關係改成 Constant。Function、Python script 及這些來源的進一步編修方式留待後續討論，本版沒有新增腳本執行接口。

## 驗證

- 11 項 TD 整合檢查：讀寫與像素、沒有更換材質／程式、過期寫入拒絕、非法數值、Expression / Bind、預設值保存與故障復原、TD Reset、Shader 隔離。
- 4 項實際 HTTP 檢查：連線碼與 Host / Origin、Shader 隔離、過期分量、只接受已曝露的 declaration ID 與合法分量。
- 7 項網頁操作檢查：雙向數值、預設值分離、輸入與焦點保留、實際像素、Expression 只讀和競爭修改拒絕。
- 既有 6 項 Expose / 改名 / Expression / 故障復原回歸通過；137 個集中語言鍵與 JavaScript 語法檢查通過。
- 獨立 Shader TOX 重載後，預設值、目前值與控制模式一致，材質有效。原生增量工程保存為 `.8.toe`，交付存檔中開發橋接停用。

測試使用 Windows、TouchDesigner 2025.32820。只驗證本次數值同步的範圍，A/B Shader 切換仍是另列的研究提案。

## 後續效能討論（2026-09-09，暫緩實作）

使用者提出：Script／Expression 等持續變動的參數，若一直同步至編輯器，可能產生額外負擔。將同步啟動條件、更新頻率和 WebSocket 的取捨留到後續效能階段；本次只記錄，不增加實作或進行效能測試。

0.2.1 現況：網頁完成一次更新後等待 500 ms 再檢查；文件隱藏時不發出讀回請求，關閉頁面即停止。只有 Uniform 目前值區或預覽具有可見版面時才讀回。每次快照仍讀取該 Shader 的全部 Exposed Uniform，尚未依選取節點或個別參數訂閱。數值沒有變化時不重新抓取預覽。這些措施不代表沒有同步成本，也不會停止 TD 本身的參數驅動或 Shader 運作。

後續以實測決定：是否只在正在編輯的頁面／相關面板開啟時訂閱、訂閱哪些參數、顯示刷新上限與合併更新、Script 驅動值與多個編輯頁面的負載，以及預覽抓取成本。比較現有輪詢與 WebSocket 的整體成本後再選擇，不預先指定 WebSocket。同步應服務於編輯器顯示，不能要求 TD 參數本身跟著顯示頻率降速。
