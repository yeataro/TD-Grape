# Uniform 寫入衝突後的欄位恢復

當 TD 的實際值或控制模式在編輯期間改變，原有 compare-and-set 會拒絕舊值的寫入；本次補上網頁欄位的恢復流程。失敗後重新讀取 TD，再顯示權威值並更新下一次寫入的比較基準。使用者可在同一欄重試原本想輸入的值，不必切換節點或重開編輯器。

每個欄位在寫入途中暫時停用，避免同一欄的過期寫入排隊。讀回失敗時維持停用，直到正常同步成功；重新建立 Inspector 也不會繞過此保護。Expression／Bind／Export 控制仍保留原本的唯讀行為。成功寫入以 TD 回傳的實際值更新欄位，包括 TD 正規化數值。沒有自動重送失敗寫入，沒有修改 Graph 預設值、revision、GLSL 或新增 Undo 語義。

8 項 Chromium 恢復情境、22 項 Value Ladder 回歸皆通過。在獨立原生 TOP 上實測刻意過期的比較值被 TD 拒絕、欄位恢復 0.3、重新輸入 0.4 成功；GPU 輸出約為 [0.399902, 0.25, 0.699707, 1]。Expression／Bind 與正式 Shader 資料保留，隔離測試區已清理。
