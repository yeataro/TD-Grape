# Router

Router 是實際保存於圖中的節點，方便整理接線。來源 → Router 與 Router → 目的地各自是一條邊，可各別設為 Wire 或 Link；不提供「Link 略過 Router」選項。

- 在 Add Node 搜尋 Router、Reroute 或「整理接線」新增。Vertex、Pixel 及 Subgraph 內皆可使用，預設可用，不放在實驗功能開關下。
- 一個邏輯輸入 `value`、一個可分接的邏輯輸出 `out`。型別跟隨來源，保留數值、矩陣、Sampler、陣列與結構的原型別；不引入轉型或 GLSL 區域變數。尚未接入來源但已被使用的 Router 會明確要求接入來源。
- 圓點採用現有接孔的 11px 尺寸，圓邊間距 3px。最多四層、十個圓，非最右列為空心。0.8.213 起，hover、選取或鍵盤聚焦時顯示上方小標題，作為拖曳把手；其餘時間隱藏。0.8.217 起，把手高度與一般節點標題列相同（41px），底部到最上方接孔中心為 21.5px；單圓及多層皆沿用此距離，滑鼠可跨過間隙移到把手。不提供縮放把手、不折疊。Link 箭頭按圓點的實際外緣定位，與一般節點接孔保持相同間距。
- 每個輸出連接依目的接孔在畫面中的 Y 位置排序；同高依節點及接孔 ID 穩定排序。超過四個目的接孔時，按上下順序分成大小相近的四組，共用最右列的四個輸出位置。此限制只影響外觀，仍遵循全圖既有容量限制。
- 從來源或目的地拖線到 Router 的圓點／整個區塊皆可連接；直接從實心圓點向目的地拉線，或從空心圓點向來源拉線。單圓時同一個圓可接入或接出。拖動上方小標題可移動 Router，也保留拖動圓點之間或外緣空隙的方式；點空隙選取，Ctrl／Shift 點選可增減選取。
- 既有刪除、複製、Undo／Redo、框選、Group、Link 導覽及圖的保存流程適用。刪除節點也刪除相連的邊，不自動重接。

設計比較圖中的目標數量、間距、空心與 Link 略過控制是設計工具，不是本版產品設定。
