# Math 連續四則運算

0.8.205 新增 Math，與既有二元 Add／Subtract／Multiply／Divide、取最大值 Max 分開。輸入以 A…Z、AA、AB…命名，最多 32 個；預設 A、B、C，所有新運算預設加法。0.8.206 將接孔排成「現有輸入 → 灰色待新增輸入 → Result」；待新增接孔跟在對應方向的列表末端，Result 位於其下方右側。Math 的待新增接孔常態顯示較暗的「新增輸入」提示。

參數頁可切換逐列運算或單一運算。逐列模式先以 A 為左側，後續列以上一步結果為左側，每列選擇運算符及右側輸入；允許重複引用同一輸入。單一運算模式將相同運算依序套用至所有輸入。切換模式保留原本逐列選擇。

運算按照列順序，不採一般算式的乘除优先；例如先 A − B，再乘 B，結果就是 `(A − B) × B`。拖線到灰色待新增接孔可增加下一個輸入；參數頁可移除末尾輸入，相關線與引用會一同整理，可 Undo。

## 臨時算式註記

建立或更改運算時，直接在現有註記文字中寫入運算關係。0.8.206 的單一運算使用簡短的 `A + B + C`，連減／連除仍由左至右計算；逐列模式保留如 `((A + B) × C)` 的括號表示先後順序。註記更新與運算修改共用 Undo；使用者另寫的文字保留，若手動刪掉或改掉自動算式，下次變更運算會追加目前算式。

這只是運算元相對關係的簡單文字格式化，不是 GLSL，也不展開實際型別轉換。節點程式碼預覽、GLSL 行號與節點雙向高亮仍是另一項重構後的未來功能，見 [UX 筆記](../discussions/UX_BACKLOG.md)。

## 型別與邊界

- 沿用一般數學節點 Auto／固定型別及純量／向量轉換規則。每個輸入在運算前轉成選定型別；不做每一列各自不同型別的推導。
- 支援數值純量、向量及矩陣，包含雙精度；不接受 bool、資源、Array、Struct。矩陣需同形，矩陣相乘限方陣。
- 除法保持 GLSL 原生語意，不自行加入除零保護或改為安全除法。
- 上游仍依既有規則產碼；未引用的可見輸入不代表上游不執行。
