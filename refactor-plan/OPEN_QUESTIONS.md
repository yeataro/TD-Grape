## 節點模組與生命週期

已確認 NodeModules 集中模組、初始化共用 NodeType、Grape 持有登記入口、圖內 Node 引用定義，以及模型／UI 分開。仍需細化：

- NodeType 的共同介面、動態接口與生成行為的精確契約；一般 Node 共用實作與子類的範圍。
- 模組／型別的 ID、版本、來源、授權欄位及重複登記的處理。
- 初始化順序、相依載入、部分失敗、重新載入與解除登記的生命週期。
- 圖內子圖定義與模組型別如何整合查詢；缺少模組時的可修復呈現。
- 打包後的模組入口、使用者安裝流程與依賴管理。現在不要求完整外掛框架。
- 可重用能力的細部分類與 helper；不重啟以單一節點語言描述所有行為的要求。

## 型別與接口

- 本地 DataType 作用域的精確層級與 API；同層衝突、結構等價性、刪除／更新被引用型別的規則。
- Input／Output 的穩定識別、Parameter 的單一或多項反查方式。
- DataType、接口語意 style 與 Parameter 外觀 style 的欄位及覆寫權限。
- 動態接口變動的值保留、型別驗證與警示方式。相容更新已有映射優先、否則依接口順序嘗試的原則。
- 除純量展開、向量裁切及 RGB 到 RGBA 補 1 外的完整轉換表；int／float／bool、矩陣、陣列與結構的規則。
- Edge 轉換描述的保存、查詢與提示 API；取代已占用接線、批次接線及規則版本變動的處理。

## 來源與宿主適配

- Source 的完整子類、分類集合 API、各類可用 Stage 與實例限制。
- Uniform、常量與特化設定的生效契約；Source style 的可用映射及各宿主回退方式。
- 新增、刪除、改名、改型別與排序時，圖內引用及宿主已有輸入的處理。
- 預設資源的保存、目的端不支援的資源，以及明確初始化／重設／移轉流程。
- Host／Target 的唯一識別、能力查詢、Binding 建立與解除、多目標控制權與 UI。
- 配對與認證、通訊協定、重連、消息去重、過期回應、失敗交付及即時值回報格式。

## Stage 與子圖

- Stage 固有能力與 NodeType／Source 要求的完整合併規則；未宣告與不限範圍的差別。
- 子圖相容性依模式、輸出及終端效果的推導方式；共享定義更新時各使用位置的驗證。
- 獨立副本對巢狀定義的複製深度、資源庫更新、圖內快照與重新連回原件的政策。
- 跨 Stage 傳值的物件與驗證契約，以及未自訂 Stage 使用預設實作的保存方式。

## 產碼與目標相容

已確認 Grape.generator 的 TOP／MAT／ISF 分工、NodeType 行為引用、每次工作上下文及結果交付。仍需定義：

- 工作上下文、程式片段／helper／符號／來源需求及位置對照的正式格式。
- Graph export、程式碼 export 與結果快取 API；節點名稱與 GLSL 可讀符號如何對照。
- ISF Pass 設定的精確欄位、尺寸表達式、緩衝初始值與宿主能力限制。
- TD 承載 ISF 的實作與驗證；Pass Index 使用 Uniform 或特化常數的選項及預設。

- 定義版本相容映射、無映射時按序對應的保存格式及斷線報告。

## 操作與更新

已確認 Change／Operation／History／Graph.updates／Binding 的責任、共用修改入口，以及每次產碼讀取一致狀態。未決部分包括：

- Operation 開始、結束、取消、巢狀與例外的 API；哪些操作需要整組回復，不把所有操作一概視為原子交易。
- Change 的欄位、作者／來源／操作識別，以及複合屬性如何避免繞過修改入口。
- History 的可逆差異／快照方式、容量、來源篩選、跨次啟動保存，以及 Grape 根層是否需要獨立 History。
- Updates 的控制物件與集合命名、flush／取消／重試 API、待辦合併和完成進度表示。
- 產碼依賴的判定、語意比較、快取及過期結果政策。原則是減少必要性之外的更新，不先承諾比較一定便宜。
- 按宿主及環境選擇更新策略的實測成本與預設；本輪不制定固定頻率或自動調參系統。
- 多人 Session 的正式歸屬、協調方式、鎖粒度、租期、權限及 Undo 衝突政策。僅保留擴充入口，不視為已完成協作規格。
